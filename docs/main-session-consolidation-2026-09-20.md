## 4. 调度原则（主会话统一派活时守这几条）

1. **子代理只能写"划给它的路径"**，其余只读 —— 共享仓库，多写者必踩。
2. **每个子代理的交付必须有可机验的判据**（"跑哪个脚本、期望什么读数"），不靠它自述。
3. **验收由主会话做**（不信子代理的自述结论）。
4. **`check-all` 当前基线是 12/3，不是 15/0** —— 验收时要用**这个基线**，
   不许把 `conveyor-context` 引起的红算到子代理头上（否则就是**假红**，会逼它去改不该改的东西）。
5. **未实施的判据级不得计作通过**；判据未落地就标 `unenforced`。
6. 提交一律 `git commit -- <paths>`（精确路径）；**绝不 `git add -A`**（共享 index，回执 §C1 已实证 3 次误伤）。
